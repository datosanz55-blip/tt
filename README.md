# TT — доставка из Китая и обмен юаней

Статический сайт из трёх страниц:

| Файл | Что это |
|---|---|
| `index.html` | Портал выбора направления: вращающийся глобус, слева — логистика, справа — обменник |
| `logistic.html` | **TT Logistic** — доставка грузов из Китая |
| `exchange.html` | **TT Exchange** — обмен рублей на юани, оплата инвойсов |

Без сборки, без фреймворков и без внешних CDN — можно просто открыть `index.html`
или залить папку на любой хостинг (GitHub Pages, nginx, Timeweb, Beget).

## Как посмотреть локально

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Как устроен глобус

`assets/js/globe.js` — canvas 2D, без библиотек.

* тянем мышью/пальцем — глобус крутится с инерцией, отпустили — медленно вращается сам;
* стрелки `←` `→` — поворот с клавиатуры, `Enter` — переход на выбранное направление;
* на шаре две точки на противоположных сторонах: **LOGISTIC** (Китай) и **EXCHANGE**;
  та, что ближе к зрителю, подсвечивает свою карточку;
* наведение на карточку доворачивает глобус к нужной точке, клик — переход;
* при `prefers-reduced-motion` автовращение и анимация перехода отключаются.

Координаты точек и адреса страниц — в начале файла, массив `SITES`.

## Что нужно заменить на реальные данные

Всё собрано в одном месте — **`assets/js/config.js`**:

* `contacts` — телефон, почта, Telegram, адреса, часы работы. Сейчас там заглушки
  (`+7 (900) 000-00-00`, `info@tt-group.ru`, `@tt_manager`) — их видно на обеих страницах.
* `logistics` — ставки $/кг и $/м³ по каждому виду транспорта, сроки, минималка.
* `buyoutFee`, `logisticsBrandFee` — комиссия за выкуп и надбавка за сложную категорию.
* `fx.rubPerCny` — курс рубля к юаню, `fx.updatedAt` — дата обновления курса,
  `fx.tiers` — комиссия по сумме сделки, `fx.minDeal` — минимальная сумма.

> Курс в конфиге проставляется вручную и на сайте помечен как индикативный.
> Если нужен автоматический курс — подставьте значение из своего источника
> в `window.TT.fx.rubPerCny` до загрузки `calc-exchange.js`.

Цифры в блоках «о компании» (1 400+ отправок, 99,2 % и т. п.) заданы прямо
в HTML — поправьте под реальные показатели или уберите блок `.stats`.

## Формы заявок

Бэкенда нет: форма собирает поля в письмо и открывает почтовый клиент
(`assets/js/site.js`, обработчик `form[data-lead]`). Перед запуском подключите
реальный приём заявок — бот в Telegram, CRM или почтовый сервис.

## Логотипы и стиль

* `assets/img/logo-*.png` — исходные логотипы с вырезанным белым фоном;
* `assets/img/mark-*.png` — только знак (грузовик / глобус с ₽ и ¥);
* `assets/img/word-*.png` — только надпись.

Чтобы обновить логотип, замените файлы с теми же именами — размеры подставляются
через CSS (`--logo-mark`, `--logo-word`, `--logo-lockup`).

Палитра взята с логотипов и задана переменными в `assets/css/base.css`:
тёмно-синий `#0B111E` / `#131E33`, стальной серый `#9BA7B4`, белый, холодный
блик `#3E7FC1` для глобуса.

Шрифты лежат локально в `assets/fonts` (`assets/css/fonts.css`), Google Fonts
не используется:

* **Oswald** — крупные заголовки, узкое плотное начертание в духе референса;
* **Pacifico** — рукописные подписи, как «Обмен юаней» и «Доставка из Китая» на логотипах;
* **Inter** — основной текст.
